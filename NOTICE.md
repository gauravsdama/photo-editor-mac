# Source and third-party notice

Photo Editor is the first-party Swift application in this directory. It uses Apple platform frameworks provided by macOS: AppKit, SwiftUI, Core Image, Metal, Network, and Uniform Type Identifiers. No third-party source or binary dependency is linked into the current app target.

The sibling OmniGen, RapidRAW, and TUI Image Editor directories were used as research or integration references. They are separate upstream projects, are not included in the packaged app, and remain governed by their own licenses and notices. The optional OmniGen command-preview endpoint only describes a command for a separately configured local checkout; it does not bundle or execute OmniGen.
